# samples —— 示例素材（怎么换成你自己的贴图）

这个文件夹是给第一次使用的人练手用的。里面已经准备好一套可以完整走通流程的假涂装贴图，
你**不需要 Photoshop**，也不需要先做真飞机涂装，先拿它们把「选贴图 → 生成 → 复制到 Community」
跑一遍，确认工具链没问题，再换成自己的作品。

## 里面有什么

```
samples/
├─ textures/
│  ├─ EXAMPLE_FUSELAGE_ALBD.PNG   1024×1024 基础色贴图（有透明区域，演示 alpha）
│  ├─ EXAMPLE_FUSELAGE_COMP.PNG   1024×1024 材质贴图（R=粗糙度 G=金属度 B=AO）
│  └─ EXAMPLE_FUSELAGE_NORM.PNG   1024×1024 法线贴图（flat 法线 + 波纹示例）
├─ thumbnail_example.png          1920×1080（16:9）示例缩略图，可直接当「缩略图」用
└─ README.md                      本说明
```

## 最快的用法（图形界面）

1. 双击项目根目录的 **`run_gui.bat`**。
2. 「① 制作涂装」→ 选择一个内置机型 → 「下一步」。
3. 「② 选择贴图」→ 点「贴图文件夹」的 **浏览…**，选择本目录下的 **`samples\textures`** 文件夹；
   列表里应出现 3 张贴图，类型分别识别为「基础色 (ALBD) / 材质 (COMP) / 法线 (NORM）」。
4. 填写涂装名称（例如 `示例涂装`），需要的话点缩略图选择 `samples\thumbnail_example.png`。
5. 「下一步」→ 选择输出目录 → 「开始生成涂装包」。
6. 生成完成后点「复制到 Community」（需先在「③ 设置」里配置 Community 路径），
   启动 MSFS 2024 即可在机库中看到这个示例涂装。

## 换成你自己的贴图

**核心规则：文件名保持不变，只替换文件内容。**

不同机模的 paintkit 贴图名字不一样（例如 `LONGITUDE_FUSELAGE01_ALBD.PNG`、
`A320NEO_AIRFRAME_FUSELAGE_ALBD.PNG`），工具靠文件名里的关键字识别类型：

| 文件名关键字 | 含义 | 游戏里管什么 |
|---|---|---|
| `ALBD` / `ALBEDO` | 基础色（颜色涂装） | 飞机外观颜色、图案、文字 |
| `COMP` / `METALROUGH` | 材质（ORM） | 金属度、粗糙度、环境光遮蔽，决定反光 |
| `NORM` / `NORMAL` | 法线 | 凹凸细节（铆钉、蒙皮接缝等） |
| `EMIS` / `LIT` | 自发光 | 灯光、屏幕、舱内照明 |
| `DECAL` | 贴花 | 门缝、警示标线等贴花层 |

所以正确做法是：

1. 找到你要改的机型的 paintkit（或从已安装涂装里解开一份贴图）；
2. 在画图软件里改 **ALBD** 那张（多数涂装只需要改 ALBD）；
3. 把文件按原文件名导出成 PNG（建议 2 的幂尺寸，如 1024×1024、2048×2048、4096×4096，
   宽高相同最佳）；
4. 把它们放到一个文件夹里（可以覆盖本示例目录，但建议另建目录，例如
   `D:\我的涂装\A320\贴图`）；
5. 在工具里选择这个文件夹即可。

> 小技巧：不需要一次放全部贴图。只放你改过的 ALBD 也可以；其余贴图会使用模板/游戏自带版本
> （克隆模式下）或保持缺省（内置机型模式下建议放齐 paintkit 的全部贴图）。

## 常见注意事项

* **不要合并图层/背景**：有透明区域（例如舷窗贴花、翅膀边缘）的贴图必须保留 alpha 通道，
  否则游戏里会出现黑边或白边。
* **尺寸最好是 2 的幂**：512 / 1024 / 2048 / 4096。工具会提示不是 2 的幂的文件，虽然不一定失败，
  但 mipmap 可能异常。
* **不要改文件名的 ALBD/COMP/NORM 部分**，否则类型识别会退化，压缩参数可能不对。
* **颜色看起来偏白是正常现象**：MSFS 的 KTX2 按 sRGB 数值直接保存，不做线性转换；
  如果发现机模在游戏里发白，属于已知的贴图流程特性，见 `docs/texture-guide.md`。
* 生成的 `.KTX2.json` / `.DDS.json` 是游戏需要的元数据文件，**不要删**。

## 重新生成示例素材（开发者可选）

示例贴图由脚本用 Pillow 生成，需要时可重新生成：

```bat
python packaging\make_samples.py
```

想换颜色/图案，直接编辑 `packaging\make_samples.py` 里的配色和图形即可。
